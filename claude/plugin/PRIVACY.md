# Privacy policy

Effective date: 21 November 2026

This policy covers Prompt Master, a skill and plugin for Claude made by Nishkarsh Shah. The other edition on the GitHub page works the same way.

## What Prompt Master is

Prompt Master is a set of written instructions, one `SKILL.md` file. It has no code, scripts, hooks, MCP servers, connectors or servers of its own.

## Data it collects, stores or sends

None. Prompt Master:

- doesn't collect, store or log anything you type
- doesn't send data to the author or to any third party
- has no network access, analytics, tracking or cookies
- keeps nothing between chats. Follow-up commands such as `pm again` and `pm undo` only use what is already in the current chat.

## How your text is handled

Prompt Master works only on the text you type in a chat. That text is processed by the AI app you are using, under that app's own privacy policy, which for Claude is Anthropic's. The author of Prompt Master never receives it.

When a draft contains passwords, API keys, or card or ID numbers, Prompt Master is instructed to replace them with `[redacted]` in the rewritten prompt.

## Children

Prompt Master is not made for users under 18.

## Changes

Any change to this policy will be made in this file, in the public repository, with an updated effective date.
